# Firefighter Robot Simulation

An object-oriented Java project simulating firefighting operations on a grid-based map with different terrain types, fire locations, and specialized robots.

The simulation features multiple robot types with distinct movement capabilities, water capacities, and terrain restrictions. It incorporates pathfinding algorithms, event-driven scheduling, and automated firefighting operations.

**Technologies:** Java, OOP, Maven, JUnit 5, JaCoCo, PIT.

The project also includes a software testing component using code coverage analysis and mutation testing to evaluate test effectiveness and identify defects.
